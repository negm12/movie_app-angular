# 🎬 Movie App - Angular

A movie management application built with **Angular** (Frontend) and **Spring Boot** (Backend). The application allows users to search, view, and manage movies using the **OMDB API**.

## 🚀 Features
- 🔍 **Search Movies** by title or ID (OMDB API integration).
- 📜 **List Movies** with details like title, genre, director, etc.
- 🔐 **Authentication** (Basic Auth with Spring Boot Security).
- 👤 **User Roles**: Admin & Regular users.
- 🛠 **Admin Dashboard** to manage movies.

## 🏗️ Technologies Used
- **Frontend**: Angular 16+
- **Backend**: Spring Boot (Java 8+)
- **Database**: PostgreSQL / MySQL (Configurable)
- **Security**: Spring Security with Basic Auth
- **API Integration**: OMDB API

## 📦 Installation & Setup
### 🔹 Clone the Repository
```sh
git clone https://github.com/negm12/movie_app-angular.git
cd movie_app-angular

npm install
ng serve
```
